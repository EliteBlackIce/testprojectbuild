Put your soundtrack files here, named after the map they belong to:
  town.mp3   yard.mp3   farm.mp3   nuke.mp3 (Atomic Acres)   ship.mp3 (Cargo Ship)   rust.mp3
They load automatically when the game is hosted (Netlify). If you open index.html straight from a folder,
use Settings > Audio > Load music files instead and pick the same files (names must contain the map word).
